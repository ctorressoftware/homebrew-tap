# Homebrew Tap

Homebrew tap for CLI tools and developer utilities by [ctorressoftware](https://github.com/ctorressoftware).

## Installation

You can install any formula directly using:

```bash
brew install ctorressoftware/tap/<formula>
```

Or add the tap first:

```bash
brew tap ctorressoftware/tap
```

## Available formulae

### FlowProbe

CLI tool for executing and verifying HTTP flows defined in YAML.

```bash
brew install ctorressoftware/tap/flowprobe
```

Project: https://github.com/ctorressoftware/flow-probe
